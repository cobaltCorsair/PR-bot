# Интерфейс PR-Bot

Снимки получены из настоящих Qt-виджетов через `QWidget::grab()`. Используются демонстрационные адреса и текст, обход не запускается.

- `campaign.png` — основная подготовка объявления, окно 1220 × 840.
- `journal.png` — журнал с примерами событий, поиском, фильтром и счётчиками.
- `compact.png` — компоновка в колонку при ширине окна 980 пикселей.
- `advanced.png` — дополнительные параметры аккаунта и браузера.

Визуальная тема вынесена в `cpp/src/window_theme.cpp`: тёплый светлый фон, тёмно-зелёная навигация и один основной акцент для действий. Иконки рисуются средствами Qt без внешних файлов шрифтов и сетевых ресурсов.

Обновление после сборки из корня проекта:

```bash
QT_QPA_PLATFORM=offscreen cpp/build/prbot_ui_tests docs/ui
```
