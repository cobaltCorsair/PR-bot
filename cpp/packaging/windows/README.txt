PR-Bot — Windows x64

1. Полностью распакуйте архив в отдельную папку, например в «Документы».
2. При первом использовании установите Microsoft Visual C++ Runtime:
   запустите находящийся здесь vc_redist.x64.exe.
3. Запустите prbot.exe. Python, Qt и инструменты сборки устанавливать не нужно.
4. Вставьте BBCode объявления и ссылку на свою тему взаимной рекламы.
5. Добавьте адреса в разделе «Форумы» или импортируйте свой файл .txt.
   Галочками можно исключить площадки из общего обхода.
6. Раскройте «Параметры входа и браузера», нажмите «Проверить обновления»,
   а затем «Установить», если предложен совместимый ChromeDriver.
7. Нажмите «Проверить», чтобы проверить форумы без публикации рекламы.
   Для этой проверки текст своего объявления можно оставить пустым.
8. В «Кампания → Куда публикуем» можно задать «Лимит реклам за запуск».
   Например, 10 — не более 10 успешных пар; пропуски и ошибки не считаются.
   «Без ограничения» (0) — весь список. После лимита остальные форумы
   сохраняются для кнопки «Продолжить», которая начинает новый запуск с этим
   или изменённым лимитом. При проверке без публикаций лимит не применяется.
   «Случайный порядок» перемешивает форумы перед новым проходом.
   «Продолжить» использует сохранённую очередь без нового перемешивания.
9. Сохраните настройки и нажмите «Запустить обход» для публикации.

Для работы нужен установленный Google Chrome.
Кнопка «Запустить обход» начинает настоящие публикации на выбранных форумах.

Хранение данных

settings.json — настройки кампании рядом с программой;
forums.txt — ваш список форумов;
log.txt — журнал последнего прохода;
progress.json — очередь и стадии отправки для продолжения после сбоя;
diagnostics — описания ошибок и снимки страниц, связанные с журналами;
logs — история всех проверок и публикаций, доступная через «Журнал → История»;
drivers/chromedriver.exe — драйвер, установленный через приложение.

Папка программы должна быть доступна для записи вашему пользователю.
Переносите и обновляйте всю папку приложения вместе с DLL и подкаталогами.
Перед заменой версии сохраните свои settings.json, forums.txt, progress.json, drivers, logs и diagnostics.
Пароль аккаунта вводится на каждый запуск и в файл настроек не записывается.

Продолжение

«Продолжить» восстанавливает незавершённый проход и сверяет уже отправленные
сообщения. При неизвестном результате бот блокирует повтор; откройте обе темы
по ссылкам в таблице и используйте «Сверить вручную…». Если есть только первая
публикация, укажите «Есть только взаимность», затем продолжите проход.
Файл progress.json содержит публичные рекламные тексты для сверки, без пароля.
Проверка без публикаций не изменяет прогресс отправки.
«Проверить выбранные» и «Обойти выбранные» действуют на выделенные строки,
в том числе отключённые. Новая обычная попытка заново проверяет темы PR-аккаунтов.

Диагностика ошибок

При ошибке сохраняются адрес, этап, описание и доступный снимок страницы.
После прохода: «Журнал → Сохранить диагностику». Для прошлого запуска
выберите запись в «Истории» и нажмите такую же кнопку. ZIP содержит журнал,
версии программы/Chrome/ChromeDriver и доступные снимки ошибок этого запуска.
Если браузер недоступен, причина отсутствия снимка будет в run.json.
Поля ввода скрываются перед снимком; остальное содержимое страницы видно.
Для старых запусков без сохранённой диагностики кнопка недоступна.

Сведения о сборке — build-info.txt; сведения о библиотеках — папка licenses.
