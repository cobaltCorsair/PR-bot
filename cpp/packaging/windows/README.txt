PR-Bot — Windows x64

1. Полностью распакуйте архив в отдельную папку, например в «Документы».
2. При первом использовании установите Microsoft Visual C++ Runtime:
   запустите находящийся здесь vc_redist.x64.exe.
3. Запустите prbot.exe. Python, Qt и инструменты сборки устанавливать не нужно.
4. Вставьте BBCode объявления и ссылку на свою тему взаимной рекламы.
5. Добавьте адреса форумов в forums.txt или выберите свой файл со списком.
6. Раскройте «Параметры входа и браузера», нажмите «Проверить обновления»,
   а затем «Установить», если предложен совместимый ChromeDriver.
7. Нажмите «Проверить», чтобы проверить форумы без публикации рекламы.
   Для этой проверки текст своего объявления можно оставить пустым.
8. Сохраните настройки и нажмите «Запустить обход» для публикации.

Для работы нужен установленный Google Chrome.
Кнопка «Запустить обход» начинает настоящие публикации на выбранных форумах.

Хранение данных

settings.json — настройки кампании рядом с программой;
forums.txt — ваш список форумов;
log.txt — журнал последнего прохода;
logs — история всех проверок и публикаций, доступная через «Журнал → История»;
drivers/chromedriver.exe — драйвер, установленный через приложение.

Папка программы должна быть доступна для записи вашему пользователю.
Переносите и обновляйте всю папку приложения вместе с DLL и подкаталогами.
Перед заменой версии сохраните свои settings.json, forums.txt, drivers и logs.
Пароль аккаунта вводится на каждый запуск и в файл настроек не записывается.

Сведения о сборке — build-info.txt; сведения о библиотеках — папка licenses.
