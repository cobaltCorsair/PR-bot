# PR-Bot

Desktop-приложение для работы с PR-темами форумов MyBB/RusFF. Основной перенос на C++ находится в каталоге [`cpp`](cpp/README.md).

## Windows: скачать сборку через GitHub

1. Откройте **Actions → Windows build** в репозитории.
2. Для новой сборки нажмите **Run workflow**, выберите ветку и подтвердите запуск.
3. Откройте завершившийся запуск и скачайте **PR-Bot-windows-x64** в разделе **Artifacts**.
4. Полностью распакуйте ZIP, установите входящий в него `vc_redist.x64.exe` и откройте `prbot.exe`.

Сборка также запускается при изменениях C++-кода, упаковки или самого workflow. Результат доступен 30 дней; для скачивания артефакта нужен вход в GitHub. Ручной запуск появляется после добавления workflow в основную ветку.

Qt-библиотеки и чистые настройки входят в архив. Для работы нужен Google Chrome; совместимый драйвер устанавливается через **Параметры входа и браузера → Проверить обновления → Установить**. Настройки и журнал Windows-версии находятся рядом с `prbot.exe`, драйвер — в `drivers/chromedriver.exe`. Подробности и локальная сборка описаны в [документации C++-версии](cpp/README.md#сборка-windows-через-github-actions).

## Сборка C++ версии

Нужен установленный Conda. Скрипт создаёт локальное окружение в `cpp/.env`, кэш пакетов в `cpp/.conda` и собирает приложение в `cpp/build`.

```bash
./cpp/build.sh
```

Запуск из корня проекта: `conda run --prefix cpp/.env cpp/build/prbot`.

Совместимый ChromeDriver для установленного браузера помещается в локальное окружение командой `./cpp/setup_chromedriver.sh`.

Запускайте приложение из корня проекта, чтобы оно читало и сохраняло `settings.json` и `log.txt` рядом с исходным проектом.

Нужен установленный Chrome и совместимый ChromeDriver. Его можно указать в окне приложения или добавить в `PATH`. В репозитории оставлен старый Windows-драйвер только для истории: новая версия его не запускает.

## Проверка публикаций

Автоматические проверки не отправляют сообщения на реальные форумы. Перед первым запуском проверьте ссылки, список форумов и шаблон; кнопка «Старт» начинает реальный обход и публикацию.

Логин и обычные настройки импортируются из прежнего JSON. Пароль из старого JSON не загружается: его нужно ввести в приложении, где он хранится только в памяти на время запуска. Новая версия не записывает пароль в `settings.json`.

`log.txt` содержит журнал с временем, этапом и адресом форума, а в конце — подробные итоги. Строки записываются сразу во время работы; после ошибки можно увидеть последнюю выполненную операцию и ссылки на подтверждённые публикации. Формат описан в [документации C++-версии](cpp/README.md#журнал-работы).

Бот подтверждает появление обоих сообщений перед отметкой об успехе. При неопределённом результате отправка автоматически не повторяется. Кнопка «Остановить» и закрытие окна завершают начатую пару публикаций и прекращают дальнейший обход.

## Python-версия

`bot_logic.py` и `PR_bot.py` — исходная реализация, оставленная для сравнения поведения. Она не является поддерживаемой точкой запуска новой версии.
